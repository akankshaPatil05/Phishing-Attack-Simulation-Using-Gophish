# Phishing Attack Simulation Using Gophish Framework

A controlled cybersecurity project demonstrating how the Gophish framework can be used to simulate phishing campaigns for security awareness and defensive assessment.

## Project Overview

This project demonstrates the complete workflow of a phishing simulation, including campaign configuration, SMTP sending profile setup, email template creation, landing page configuration, target group management, campaign execution, and monitoring of user interactions.

The simulation is designed for an authorized and controlled environment to help identify phishing awareness gaps and improve organizational security practices.

## Key Components

* Gophish Framework
* SMTP Sending Profile
* Phishing Email Template
* Simulated Landing Page
* Users & Groups
* Campaign Configuration
* Campaign Monitoring
* Results Analysis
* Security Awareness Recommendations

## Objective

The primary objectives of this project are to:

* Evaluate user awareness of phishing attacks
* Identify potential weaknesses in email security awareness
* Analyze user interaction with simulated phishing emails
* Demonstrate phishing simulation methodology
* Recommend security awareness improvements

## Disclaimer

This project is intended strictly for educational, cybersecurity awareness, and authorized security assessment purposes. Phishing simulations should only be conducted with appropriate authorization and within a controlled environment.
